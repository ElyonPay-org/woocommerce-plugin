# Assets de la fiche WordPress.org

Placez ici les visuels de la page du plugin (ils sont automatiquement copiés
vers le dossier `assets/` du SVN par le workflow de déploiement) :

- `icon-128x128.png` et `icon-256x256.png` (ou `icon.svg`) — l'icône
- `banner-772x250.png` et `banner-1544x500.png` — la bannière
- `screenshot-1.png`, `screenshot-2.png`, ... — les captures (numérotées dans
  l'ordre des légendes du readme.txt)

Ce dossier `.wordpress-org` n'est PAS inclus dans le plugin distribué.
